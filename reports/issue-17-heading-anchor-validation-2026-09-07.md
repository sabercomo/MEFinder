## 只读诊断

### R9《战斗美少女的精神分析》JA→ZH

中文六章均为可提取文本，不是扫描图片，因此排除 OCR／解析层缺失：

- 第一章：JA order 126 为 `第一章`；ZH order 202 为含广告残留、无章号的
  `“御宅”的精神病理`，属于未编号标题。
- 第三章：JA order 979 为 `第三章 海外戦闘美少女事情`；ZH order 999 为
  `03日本之外战斗美少女的情况` 并与副标题、正文同段，属于标题并段。
- 第六章：JA order 2591 为 `第六章`；ZH order 2506 为 `06菲勒斯少女的生成` 并与正文同段，
  同属标题并段。

其余中文章标题同样存在于文本层：第二章 order 769、第四章 order 1358、第五章 order 1697。
原检测器在完整文档上可以借目录恢复这些标题，但实际对齐先截取审核正文，再检测标题，导致目录上下文
丢失；同时 order 714、1357 的中途 `注释` 被误作全书尾注终点。两者叠加后，目标侧零章标题，正文仅靠
7 个 `name:` 锚点跨约 3400 段。

### n93《法哲学原理》DE→EN PDF

- 德文原 PDF 的正文页可见 `§ 202`；数据库 `pdf_pages.payload_json.text_raw` 也包含该块。分段器把页顶
  `§200`、`§201`、`§202` 的数字归一成同一跑眉模板后误删，属于分段清理误判，不是源书缺失。
- 英文原 PDF 正文页肉眼可见 `§203`，但 PDF 原生文字层和已存 `text_raw` 均没有该字符块；这不是标题
  正则格式变体。本修复不虚构文字层不存在的标题，目标侧 `paragraph:203` 仍为阴性。
- 旧 target order 8259 的尾注 `§ 203` 已在尾注排除区。v13 新增 26 个更早的合法节号后它映射为
  order 8281，`_excluded_anchor_indices` 仍返回 true，未进入锚点抽取。

## 最小修复

1. 重复页眉清理只豁免完整匹配通用 `§N`／`第N节` 规则的编号段落标记；章、篇、部跑眉仍去除。
2. 在完整文档上抽取结构锚点，再把审核正文范围内的锚点平移到切片坐标；
   `find_heading_anchors` 的段号优先与最长单调章节链配对逻辑不变。
3. 只有位于最后一个可识别章节标题之后的 `注释` 才终止章节扫描，允许书中章末注释之后继续出现章节。

没有加入书名、source id 或两本书专用正则。
