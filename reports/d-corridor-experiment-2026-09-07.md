## 结论（先说结果）

**arm A、arm B 在「沿用落库分数与现行阈值 + 现行转移/惩罚模型」的约束下，对 9 条可行动夹具
正确重接 0 条。这是阴性结果。** 原因不在 DP 搜索，而在**代价模型**：正确译文的相似度其实更高
（E5 分数站在正确一侧），但要把 pivot 接到正确 target，必须**跳过版本独有的编者插入段 /
OCR 噪声段**，而现行 gap 惩罚（2.2/段）过高，使错误的「相位错位」路径在走廊内全局更省。
锚点间重跑 DP 只会复现落库结果。

### 3. arm B（走廊窗口重对齐）= 复现落库

直接用**生产 DP** `_align_partition` 在每条夹具的锚点走廊内重跑（同分数、同阈值、同转移）：

对角线随括号漂移而与落库略有出入，但同样到不了正确 target（反而更远）。arm B 无增益。

### 4. arm A（边界局部重接）⊆ arm B

arm A 只在相邻链接间移交首/尾成员，是 DP 搜索空间的**真子集**；既然 DP 已是走廊内全局最优

## 逐条病因（为什么修不了）

- **版本独有编者插入致相位错位**（n82/n60/n80/n24/n98）：英文/EPUB 版比德文原书多出
  `Addition`、译者注、“comfortable” 之类展开段；德文无对应。正确对齐要 gap 这些段，惩罚过高。
- **OCR 噪声段虚高相似**（n28）：英文文字层乱码段（`Ð!`/`tio;`）与德文短段虚假匹配，正确
  译文（T1193）被相位挤开。
- **远距漂移**（n41）：正确 target 距落库落点约 1382 段，gap 代价 3560，DP 射程外。
- **节号锚点卡阈值 + 单调消费**（n93）：pivot 为孤立标题 token `§ 203`，与正文 T4609–4611
  成组仅 0.83（恰卡阈值 rejected）；更紧成组可达 0.93，但相邻正文段已被邻链消费，DP 不改组。
  这是**分段/阈值**问题，非走廊 DP 问题。
- **gap 优于正确**（n53）：正确 T562–564 sim 0.928，但落库选择 gap（unmatched），因为接上它
  会连累相邻更贵；同 §2。
- **双生命题**（n88）：allow-unfixable。

## 验收判定

- 仍失败 9 条（n88 允许失败）中正确重接 **0 条 < 门槛 8 条 → 未达标**。
- 回归控制：**vacuously 满足**——D 未采纳任何重组（冲突只记录不合并），故 n74 未降级、
  60 条正确金标零回归、副文本/注释/噪声零新增配对。但这同时意味着 D 未产生任何修复。

## 推进方向（超出 D「沿用落库分数与阈值」约束的真正杠杆）

阴性结果把杠杆定位到**代价模型 / 分段**，而非走廊搜索：

1. **上下文感知 gap 惩罚**：对检出的版本独有编者插入段（`Addition`/译者注/编者展开）与 OCR
   噪声段，降低其 gap 惩罚，让 DP 敢于跳过——这是 n82/n60/n80/n24/n98/n28 的共因杠杆。
2. **标题 token 并入正文分段**：把 `§N` 这类孤立标题 token 与其正文段合并后再对齐（或对
   锚点邻接段放宽阈值），修 n93 类卡阈值。
3. n41 远距漂移、n88 双生命题：维持已知限制，随 0.5.x 发布如实标注。

在未做代价模型工作前，「note-channel 100 条随机 11% 错配」的已知上界不变。D 两步法本身
（锚点走廊内二次对齐）在当前分数/惩罚约束下**不是**这 11% 的有效杠杆——记录在案，路到此为止。
