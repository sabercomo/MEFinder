# D 第 1 杠杆实验：上下文 gap 惩罚（单变量，2026-09-07）

issue #18 下一轮的第一个杠杆。生产库、正式算法全程只读不动，一切在 v13/v21 副本上进行。
**唯一变量 = 对结构性检出的版本独有 apparatus/OCR 噪声段所施加的 gap 惩罚**；embedding、锚点、
分段、接受阈值(0.83)、匹配代价全部固定。为此把 60 条金标 + n74 所在的 16 个 pair 全部按 v13/v21
重建到副本。驱动 `scripts/d_gap_penalty_experiment.py`，检测器/带折扣 DP 在
`alignment_corridor_refine.py`（`test_alignment_corridor_refine` 钉死）。结果
`reports/d-gap-penalty-experiment-2026-09-07.json`。

## 验收器（真读真比，非固定打印）

对 60 条人工判「正确」金标 + n74，逐条：v12→v13 定位 pivot、取其在走廊 DP 路径中的链接、算
组相似度 → **最终接受状态**（≥0.83 才 accepted），与金标目标比较。基线（惩罚 2.2 = 生产）：
**49/60** 金标在 raw-DP 基线上「接受且落在正确目标」;另 11 条 pivot 落在正文走廊之外（副文本/
注释区，即生产 note-channel 后处理与 raw-DP 的已知 ~4% 分歧），逐条追踪但基线不计正确。n74 基线
= accepted，target `[1484,1487)`，conf 0.846。

**n93/n41 的金标是「范围」不是「必须完整匹配的成员集」**：`gold_is_range=True`，只作重叠诊断，
**不计入「修好」**（修正上一版把目标截成前 3 段做约束的误判）。

## 检测器先核对（n82 主诊断案例）

`detect_edition_apparatus` 只用**文本结构**（apparatus 标签词表 + OCR 噪声比），不看夹具编号/
位置/embedding/金标。n82 走廊 `[4510,4569)` 实测命中：

| 命中段 | 文本 | 类型 |
|---|---|---|
| T4516 | `Addition (H).` | apparatus 标签 |
| T4528 | `Addition (H).` | apparatus 标签 |
| T4526 / T4527 | `"i , .. ' .` / `1'1 ' ;` | OCR 噪声 |

**未命中**（且不应命中）：T4517–4518（`comfortable` 展开正文）、T4519、T4520（`Translator's note:…`
整句）——这些是 Hotho「Addition」块的**正文内容**，结构上判不出、且用户明令不得仅凭标签就断定整块
无对应。附：纯相似度阈值（0.80 误报正文 T4567、漏 T4516）与互为最近邻（n82 走廊 42/59 段全被标记）
两种 embedding 信号都**不可靠**，已弃用——E5 跨语相似度在 0.78–0.89，分不开插入与正文。

## 结果：基线 vs 三档折扣（2.2→1.5/1.0/0.5）

| 指标 | 惩罚 1.5 | 惩罚 1.0 | 惩罚 0.5 |

| 60 金标回归 | **0** | **0** | **0** |
| 金标链接变化（任何） | 0 | 0 | 0 |
| n74 | 不变(accepted) | 不变 | 不变 |
| 非调参走廊复核（60 金标跨 16 pair） | 0 回归 | 0 回归 | 0 回归 |

主案例 n82 在所有档位**从不改变**：落库链接 P2266→T4516–4518，正确目标 T4521；要够到 T4521 必须
gap 掉 T4517–4520（`comfortable` 展开 + 译者注 = 版本独有正文），而检测器只标了 T4516 标签与 OCR，
**没标这些正文段**，所以 DP 仍接在原处。n24、n60 同理不变。只有 0.5 的激进折扣把 n28 推到**新的错误
目标**，仍未修好、且制造新错配。

## 结论（按证据，收窄）

**当前检测器（apparatus 标签 + OCR 噪声）叠加三档 gap 折扣，未带来修复**：共修好 **0/9**，激进档
反而新增错配；60 金标 0 回归、n74 不变。在本次尝试里，能被结构原则性检出的只有 apparatus 标签与
OCR 噪声，而 n82 这类要够到正确目标需 gap 的是**版本独有插入的正文内容**（`comfortable` 展开等），
本检测器没标到它；两种 embedding 信号（相似度阈值、互为最近邻）在跨语 E5 上也没分开插入与正文。

**注意边界**：这是「当前这套检测器 + 这几档折扣未修好」，**不能推广成「版本独有正文无法被任何方法
原则性识别」**——只是本轮试的这几种失败，不排除别的检测思路（如结合上游结构标记的块边界、双侧一致性、
或专门的版本对照）可行。金标强制路径仅在 `d_corridor_experiment` 作诊断，未计作修复。

**这一小实验（此检测器 + gap 折扣）到此为止，不扩大验证。** 该假设是否换检测思路再试，留待后续。
