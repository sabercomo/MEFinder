# MEFinder 0.6.5

## 更新内容

### 译本对照

- 默认启动先观察 Zotero 状态，再读取或复用共享摘要。已有同步历史不再触发同次启动内的重复摘要与总览请求；轻量对齐总览仍在摘要完成后加载。
- 隔离库实测（462 篇文献、8 个作品组、70 条对齐记录）：无磁盘缓存时入口等待中位数由 2.906 秒降至 2.308 秒，命中缓存时由 2.137 秒降至 1.827 秒。见 [计时报告](../reports/translation-work-startup-2026-11-22.md)。
- 后续 Zotero 同步仍会刷新目录；检索、页码、数据库、HTTP 与 MCP 契约不变。

## 升级须知

- **数据库仍为 v13**，本版未新增 schema 变更；0.6.3 及更早版本仍无法打开升级后的库。
- 本包仅 macOS arm64，最低 macOS 14，ad-hoc 签名、未公证。Windows 与 Intel 包未重建。
- 本轮仅本地测试，不涉及标签、Release 或 Homebrew；v0.6.4 的公开标签与 12 个附件保持不变。
