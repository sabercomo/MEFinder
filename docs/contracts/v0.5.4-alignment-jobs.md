# v0.5.4 译本对齐任务：组件不可用与取消

2026-09-14：阶段 2A 开发源码在组件不可用时返回明确的安装提示；本契约尚未进入已发布的 v0.5.4 安装包。

沿用 [v0.5.3 后台任务契约](v0.5.3-alignment-jobs.md) 的请求字段、任务轮询、成功、取消及拒绝行为，补充以下终态：

- 模型未安装、计算运行时缺失、协议不兼容或 worker 无法启动：HTTP 503，响应为 `{ "error": "具体安装或兼容提示", "component_unavailable": true }`。
- 探测或计算期间取消：HTTP 200，响应为 `{ "ok": false, "cancelled": true }`。
- 计算或写入失败仍为 HTTP 500；组件卸载及升级操作不在阶段 2A 范围内。

`POST /api/text-alignments/generate` 直接返回上述终态；通过 `/start` 创建的后台任务由 `GET /api/text-alignments/status?job_id=...` 返回同一终态状态码和响应体。HTTP 503 在这里表示该对齐任务所需组件不可用，不表示搜索服务被关闭。
