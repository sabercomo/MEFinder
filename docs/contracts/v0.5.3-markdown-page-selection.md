# v0.5.3 Markdown 按页导出契约

2026-09-08：开发功能，独立于繁简检索 PR；未发布安装包。

## 请求与兼容性

`POST /api/document/export-markdown` 保留原请求，增加可选字段：

```json
{
  "source_id": "book-id",
  "page_selection": {"mode": "printed", "pages": "12-18,25"}
}
```

`mode` 为 `printed`（原书页码）或 `physical`（从 1 开始的 PDF 物理页码）。`pages` 是非空字符串：逗号分隔，数字范围闭区间，可逐个填原书标签如 `iv,v`。最多 512 字符、10000 页；重复项去重，输出仍按书中顺序。非数字标签不支持范围推算。省略字段保持原整书导出；显式 null、空对象及无效选择均返回 400。

页码类型与 `export_options.page_marker_mode` 相互独立：即使输出不显示页码注释，仍按相同来源页筛选。

## PDF 正文和脚注

1. 用已入库页面解析选择，不按屏幕重排、不重新 OCR。
2. 在完整文档上沿用页面重建、页眉清理、章标题与脚注配对。
3. 按正文块的导出物理页归属筛选；已可靠重建的跨页块按目标页归属选择。
4. 保留所选正文引用的脚注定义，包括位于未选择的章末位置的定义；在原章末对应位置（或所选章片段末尾）输出。未选择正文的脚注不带出。
5. Markdown `[^note-id]` 与 `[^note-id]:` 标识保持一致，多引用共享定义只输出一次，供支持 Markdown 脚注的阅读器跳转。

页码缺失/重复时返回 400，不悄悄减少范围；合页 PDF 不做未证实的左右半页裁剪，原书页模式报错并提示用物理页。完整文档中仍有无法重建的已知跨页块时，保守拒绝精确按页导出。未知脚注不猜配对；保留原标记并提示，不能保证跨页注释或原始错误标记的补全。

## EPUB

仅允许 `printed`，只读取已有 `epub_page_list`/`epub_pagebreak` 标记。无出版方页码、标签重复出现于不连续位置、段落跨页而缺少页内边界时返回 400。

当前 EPUB 入库模型没有保留原始超链接脚注关系。因此本功能可选取带出版方页码的正文，但不保证将页外注释带出；界面、响应和文件均注明。不得将 PDF 规范化脚注能力声称为原始 EPUB 链接恢复。

## 输出

保留原响应字段；`page_count` 为所选源页面数量，EPUB 同时返回选中 `paragraph_count`。增加 `page_selection`（实际物理页或 EPUB 标签，PDF 附 note_count）与 `warnings`。

PDF `footnote_report` / `reconstruction_report` 仍基于完整文档；前者显式标注 `report_scope=whole_document`，selection 子项单列导出正文块、引用与定义数量。

文件保留原文和原 YAML 书目，YAML 后附选择范围注释；文件名包含范围类型和摘要，避免覆盖同书整本导出。相同选择再次导出仍沿用原有替换策略。
