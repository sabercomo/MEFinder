# v0.5.3 译本对齐后台任务

2026-09-09：桌面前端通过短请求轮询等待对齐，避免 WebView 长请求超时；旧同步入口继续兼容。

- `POST /api/text-alignments/start`：请求字段与 `/generate` 一致，必填
  `document_group_id`、`pivot_source_file_id`、`target_source_file_id`，可选布尔 `force`。
  立即返回 HTTP 202 与 `{job_id, status: "running"}`。
- 当前任务运行期间，相同请求返回同一个任务 ID，不重复启动；不同请求返回 HTTP 409，
  提示等待或取消当前对齐。字段不合法返回 HTTP 400。
- `GET /api/text-alignments/status?job_id=...`：运行中返回同样的 HTTP 202；完成后返回
  原 `/generate` 的终态状态码及响应体：成功 200（`ok/result/event`）、取消 200
  （`ok:false,cancelled:true`）、拒绝 400（`error`）、运行失败 500（`error`）。
- 任务状态仅保存在当前应用进程中，保留当前／最近一项任务。任务 ID 不存在或被后续任务替换
  返回 404；查询字段非法返回 400。已完成的对齐仍由原数据库事务持久化。
- 前端每秒查询一次状态，终态错误如实显示，取消仍使用 `POST /api/text-alignments/cancel`。
- `POST /api/text-alignments/generate` 保持同步契约，供既有客户端使用。

完整路由清单见 `v0.5.3-http-api.json`。
