# v0.4.4 MCP v1 只读工具契约

更新日期：2026-08-14

状态：0.4.4 第一阶段冻结

机器可读契约：`docs/contracts/v0.4.4-mcp-v1-tools.json`

## 1. 范围

MCP v1 只提供三个只读工具：

1. `list_documents`：筛选本地文献并取得稳定的 `source_file_id`；
2. `locate_quote`：定位原句并返回可核查证据；
3. `read_document_window`：从命中位置继续读取有界上下文。

v1 不包含导入、删除、页码校准、题录修改、备份恢复和数据迁移。工具不访问网络，不返回本地绝对路径，也不返回前端 HTML。

## 2. 权威定义

JSON 文件是工具名称、输入 schema、精简输出 schema、安全标注、错误码和初始化 instructions 的权威定义。本文件解释语义；两者冲突时，以 JSON 为准并修正文档。

机器可读文件在根级 `$defs` 复用公共类型；MCP `tools/list` 单独发送每个工具时，适配层必须把该工具实际引用的定义及其传递依赖附到对应 `outputSchema.$defs`，保证该 schema 脱离合同文件后仍可独立解析和校验，同时避免向模型重复发送无关定义。

所有成功结果都包含 `schema_version: "1"`。字段只能向后兼容地增加；删除字段或改变字段语义必须发布新的主 schema 版本。

三个工具统一声明：

```json
{
  "readOnlyHint": true,
  "destructiveHint": false,
  "openWorldHint": false
}
```

## 3. 页码语义

- `physical_page` 只表示 PDF 文件中的物理位置，索引从 0 开始；它不能自动作为正式引用页码。
- `citation_page` 只表示经 MEFinder 现有页码规则确认、可用于引文的页码。
- `citation_page.status=calibrated` 表示 PDF 引用页码已经校准或验证。
- `citation_page.status=verified` 表示 Word 页码已经验证。
- `citation_page.status=uncalibrated` 表示有物理 PDF 位置，但没有可安全引用的页码。
- `citation_page.status=unavailable` 表示当前记录没有可用页码位置。

适配层必须读取现有结构化字段作出上述转换，禁止解析 `page_display` 中文字符串反推状态。

## 4. 搜索证据语义

`locate_quote` 返回的是候选证据，不返回“文献已核实”之类的最终裁决：

- `paragraph_id` 标识一次真实出现位置；相同文字出现在多个段落时不得再次按文本去重。
- `match_type` 和 `match_score` 说明检索方式及排序证据，不等价于题录或引文结论已经确认。
- `context_before`、`context_after` 只返回现有搜索引擎提供的相邻正文。
- `reader` 给出继续调用 `read_document_window` 的自然位置。
- 输出禁止包含 `highlighted_html`、`copy_text`、绝对路径和内部调试证据。

无结果是成功响应：`total=0`、`matches=[]`。它不能转换成故障，也不能伪造候选。

## 5. 错误语义

边界只转换已知错误；未知异常记录到 STDERR 后按 `internal_error` 失败，不伪装成“未找到”。

失败调用返回 `isError=true`；其 `structuredContent` 按机器合同中的 `errorSchema` 返回，文本 `content` 只保留同一错误对象的紧凑 JSON，不包含本地路径、堆栈或原始异常消息。

| 错误码 | 场景 | 可重试 |
| --- | --- | --- |
| `invalid_input` | 参数不符合 schema | 否 |
| `index_not_found` | 当前数据根没有索引 | 否 |
| `index_unavailable` | 索引正在替换、锁定或暂时不可读 | 是 |
| `source_not_found` | 文献 ID 不存在 | 否 |
| `unsupported_source_type` | 文献类型不支持结构化阅读 | 否 |
| `internal_error` | 未归类故障 | 否 |

## 6. 本阶段验证边界

0.4.4 第一阶段只验证契约与既有业务基线，不实现 MCP Server。公共合成夹具必须覆盖：

- PDF 已校准引用页；
- PDF 只有物理页、引用页未校准；
- Word 文献；
- 精确搜索结果与阅读窗口；
- 无搜索结果。

后续服务层和 MCP 协议层必须复用同一夹具，不依赖用户个人文献库。
