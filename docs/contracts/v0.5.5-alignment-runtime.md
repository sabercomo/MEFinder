# v0.5.5 对齐运行时生命周期（未发布）

2026-09-16：沿用现有 `/api/text-alignment/runtime`、模型与对齐任务端点，无新增请求字段。

- 对齐任务和模型下载持有共享运行时使用锁；模型下载的租约覆盖安装回执发布。升级、卸载先阻止新任务，再等待已准入操作结束。POSIX / Windows 均跨进程协调。
- 维护期间的新对齐任务沿用 `component_unavailable` / HTTP 503；新模型下载可能已被后台接口接收，但其状态应变为 failed，并显示维护原因，不启动计算子进程。
- 卸载默认删除运行时及该组件模型，不弹确认窗口，不删除文献、笔记、已有对齐成果和人工修正。
- 应用退出取消模型下载和组件安装，回收子进程并等待线程。关闭超时必须返回未完成，不能报告成功。
- 重启恢复持有组件操作锁后才能恢复目录、清除遗留维护标记；不得清除其他实例仍在使用的维护标记。
- 缓存清单缺少 alignment 时，对齐组件使用应用内置定义，其他组件清单来源不变。
- 对齐组件使用 Python 3.12；NumPy 2.5.2、fastembed 0.8.0；ONNX Runtime 默认 1.29.0，macOS Intel 为 1.23.2。此平台覆盖仅属于 alignment，不影响 OCR 组件。
