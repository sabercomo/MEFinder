# v0.5.9 导入任务前端边界

2026-10-13：任务状态由 `78-import-jobs.js` 统一持有，导入界面读取快照并发送命令。

## 所有权与装配

- `MEFinder.importJobs` 持有队列项、上传状态和轮询定时器。`00-state.js` 不再暴露 `importStore`。
- `snapshot()` 返回新数组及逐项浅副本；任务字段是标量与不可变的浏览器 `File`。`add(item)` 复制输入，调用方不能通过保留引用修改内部任务。
- `80-import.js` 注入渲染、确认、提示、恢复接口选择及文献刷新回调。服务不读 DOM、文献库状态或解析设置。
- 数字文件名前缀保证服务先于 `80-import.js` 装配；保留既有 `MEFinder.imports.pollJob / loadResumableImports / loadActiveImports` 入口。

## 命令与状态

- 上传、在途任务恢复、暂停任务恢复、取消、继续、三类解析接口重试、书目抽屉重新解析均通过任务服务更新状态。
- 界面状态保持 `queued / processing / done / error / paused`；后台 `cancelling` 对应 `processing + cancelRequested`，停止完成返回 404 后才移除。
- 普通任务 404 仍报错，取消期间查询失败仍保留可重试任务；后台清理失败展示后端错误。
- 同一队列项、同一后台任务仅保留一个轮询监听。删除、重复导入合并或切换后台任务使旧监听失效；旧响应和旧定时器不能写回。
- 完成后调用宿主文献刷新；暂停、失败和完成均停止轮询。正常处理中维持原 2.5 秒间隔。
- 继续解析和切换接口的费用确认、串行批量继续 / 取消、索引失败不再解析等既有行为保留。

HTTP / MCP 接口与数据库不变。本契约只描述窗口内前端状态，不增加跨窗口协调或持久化。
