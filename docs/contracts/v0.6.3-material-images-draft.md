# 图片素材接口草案

以下变更基于 0.6.3 开发，复用本机素材库已有路由。

- `GET /api/materials` 在文字素材快照中增加 `material_images` 和 `material_image_tags`。图片以 SHA-256 字符串作为 `digest`；`origin` 是 JSON 字符串，外部图片为空对象，PDF 截图保留文献 ID、从 1 开始的物理页、已校准的印刷页码及相对于旋转后页面的归一化裁剪边界。
- `GET /api/materials?image=<digest>` 返回已登记的 PNG 或 JPEG 原始字节。
- `POST /api/materials` 的 `preview_pdf` 操作接收 `source_id` 和 `page`，返回 PNG 预览、页码、页数和文件版本标识。
- `collect_image` 接收标签和可选说明。外部图片提交标题和 Base64 编码的 PNG / JPEG；PDF 截图提交预览返回的文件版本标识、文献 ID、物理页及 `[左, 上, 右, 下]`。同一内容重复保存时，返回已有的 `digest` 和 `created: false`。
- `edit_image` 接收 `digest` 及要更新的 `note` 或 `tags`。
- 备份 ZIP 中的 `config/materials.json` 包含图片元数据与标签，文件位于 `materials/images/<digest>`，恢复时核验哈希。
