# v0.5.5 作品总览查询参数

2026-09-19：在现有 `GET /api/translation-works/overview` 增加可选筛选；不改变默认响应和路由。

| 参数 | 含义 |
|---|---|
| `include_statistics` | `0` 跳过链接详细统计；`1`（默认）计算精确统计。其他值或重复参数返回 400。 |
| `source_id` | 仅返回此文献所在作品，作品内版本关系完整保留。 |
| `target_id` | 必须同时提供不同的 `source_id`，只返回这两个版本之间的关系。 |

- 参数均只能出现一次；文献 ID 使用现有校验规则，空值和未知参数返回 400。
- 无对应作品/版本对返回空 works/pairs，不伪造状态。索引重建仍为 503，存储错误仍为 500。
- 轻量响应保留 `matched_segment_ratio`、`review_count` 两个字段为 null；null 表示未统计，不是零或没有待检查。
- `status`、`stale_reason`、`via_source_file_id`、`completed_at` 与语言信息按原规则计算；不修改已存对齐。
- 阅读器使用 `?include_statistics=0&source_id=…`；作品首屏使用 `?include_statistics=0`；显示某对版本的统计时用 `?source_id=…&target_id=…`。

证据：[延迟复审报告](../../reports/startup-reader-latency-2026-09-19.md)。
