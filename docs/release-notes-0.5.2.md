# MEFinder v0.5.2

> 这个版本主要围绕译本对照做改进：新增更准确的 E5 Large 对齐模型（按需下载、设置里选择），并给自动对齐加了几道质量把关，把字面相同、含义不同的错配拦下来。另外优化了结构化阅读和管理作品组的界面。

## 译本对齐

- 新增 **E5 Large** 对齐模型：在设置的“译本对齐”里可以在 MiniLM 和 E5 Large 之间选择。E5 Large 对齐更准，推荐使用；MiniLM 体积更小，之前已下载的继续可用，不受影响。
- 对齐模型默认不下载——译本对照不是每个人都需要，第一次使用时再按需下载。下载时显示已下载大小、总大小和百分比，中途断开再下会接着上次的进度继续。

### 三道新的质量把关（本次重新发布的重点）

对齐的核心算法没有改动，只是在结果生成前后加了检查，结构锚点不受影响：

- **同一个词、不同的意思**：原文和译文里字面相同但含义不同的词，以前可能被当成锚点、把不相干的段落连在一起；现在相似度不够的这类锚点会被直接丢弃。
- **每章重新编号的脚注**：有些书每章注释都从 1 重新数，纯数字编号以前会被误认成对应点；现在小于 100 的裸数字不再用作锚点，跨度明显不合理的锚点也会被拒收。
- **信息量太低的段落**：整段对照如果只靠没什么内容的段落撑着（比如只有 ①②③ 圈号的脚注块），会降级处理，不再当成可靠对应；正文里正常的 `$^{②}$` 上标引用不受影响。

需要注意：升级到本版后，以前生成过的对照会失效，要重新生成一次。模型不用重新下载，已算好的向量缓存会复用，重新生成只是花点时间。

### 对齐质量，如实汇报

- 从全部文献里随机抽了 100 条对照结果人工核对（抽样固定、可以复现）：60 条完全正确、29 条基本对应、错配约 11%（统计误差范围约 6%–19%）。以前出过问题的两个案例——《消费社会》的同词异义错配、《战斗美少女》的跨章注号错配——重新生成后都确认消失。
- 还有没解决的已知问题，如实列出：① 长段落密集的地方，约一成的链接会偏到相邻段落，后续在 #18 跟进；② 《战斗美少女》(R9) 可用锚点太少，对照覆盖率偏低，后续在 #17 跟进。

## 界面优化

- 管理作品组：弹窗界面重做，成员格式标识更清楚，打开时自动刷新到最新状态。
- 结构化阅读器：双栏对照的头部改成两行布局，版本选择换成真正的下拉框；默认按流式排版阅读，想保留原书断行的可以切回“复刻断行”。
