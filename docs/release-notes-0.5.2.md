# 0.5.2 本地实验构建说明

2026-09-06：安装包、便携包和全库 E5 重跑已完成，pytest 全绿；但跨书质量门禁未全部通过，不能作为“E5 全库可可靠自动定位”的正式推广依据。默认模型仍为 MiniLM。完整证据见 `reports/e5-full-rerun-2026-09-06.md`。

## 文本对齐

- 可选 MiniLM 与 multilingual-e5-large；默认仍为 MiniLM。E5 标记为“实验档”，CPU 推理更慢，下载约 2.24 GB。
- 模型向量缓存、对齐结果按模型隔离；运行参数保存模型和阈值。切换模型后需要重跑已有配对。
- E5 普通链接低置信度阈值为 0.83，注释块阈值 0.80、margin 0.05 仍待标定。
- 阈值依据为《性别麻烦》37 条原书 AI 复核，不是独立人工金标，也不是跨书质量保证。5 条完整正确样本中，0.829 的一条仍会被拒绝。
- 新运行记录正文范围及区域规则版本，范围外段落以单侧 rejected 行保留，禁止自动定位回退进入这些区域；不改 DP 转移和代价逻辑。
- 书前范围使用结构标题推断，书后识别译后记、致谢、索引等标题。重复章末注释不作为全书终点；正文内脚注暂沿用既有逻辑。支持按精确分段集记录复核正文范围，后续切换模型或强制重跑继续复用。

## 已知限制与验收状态

- 本批 20 个分段集已核对原书边界，17 个方向运行（15 个书对）已真实 E5 重跑，范围外自动链接为零。但标题缺失、OCR 误识别、未编号章节的新书仍可能识别不足。
- 全库 34 条定向抽查为 11 正确、11 部分对应、12 错配（非无偏准确率样本）。法中《消费社会》的同词异义锚点、日中《战斗美少女》的跨章注号锚点仍造成错配，书内译注和 OCR 符号仍可能被接受。不能把这些情况宣称为“副文本问题全部解决”。
- 副文本排除也会移除确有对应关系的作者致谢：37 条中的第 35 条属于此情况，不能宣称保留 9/10 条正确或部分对应样本。
- 单侧排除行 confidence=0 是无配对占位，不是余弦相似度；分数统计必须剔除单侧排除行，不能把 unmatched 降幅直接算作质量收益。
- MiniLM 固定成员集合离线评分见 `reports/e5-region-validation-2026-09-05.json`，不是重新运行 MiniLM DP 后的链接评分。
- Bertalign 原始两阶段 DP 已在一个复核正文走廊完成真实拼接 E5 实验和原书抽查，未接入正式路径；其新增正确候选与现有链接重叠，不能直接追加落库。
