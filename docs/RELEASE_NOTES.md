# 文献原句定位器 v0.3.8

- 修复少量离群候选干扰主体偏移判断的问题，以反复出现的主导偏移为准；
- 修复 `无序`、`秩序`、`顺序`、`次序`、`工序` 等词被误认为「序」类前言标记的问题。
