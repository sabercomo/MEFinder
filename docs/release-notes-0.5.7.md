# v0.5.7 迭代说明

- Windows 无边框主窗口补齐上边缘、左上角、右上角的拖动缩放：原实现仅支持左/右/下及两个下角。顶部 8px 进入系统缩放，其下仍可拖动标题栏和点击窗口按钮；最大化时不显示缩放热区。记录见 `reports/windows-top-resize-2026-09-28.md`。

- Windows 主窗口在首个页面加载完成后显示，减少浏览器初始化期间整窗浅蓝空白；仅首次显示，刷新不抢回已最小化窗口。此项改善显示时机，不代表启动总耗时缩短，也不等同于文献库摘要/正文范围缓存优化。测量与限制见 `reports/windows-startup-blank-2026-09-28.md`。
- 修复启动后最小化按钮带蓝色焦点框：窗口改为页面就绪后才显示，激活时 WebView2 把焦点按 Tab 方式送到第一个可聚焦元素（最小化按钮）。标题栏按钮现只在键盘导航时保留焦点。本机开发版 `dist/MEFinder` 已按此修复重建替换，启动截图确认无焦点框。

- 从远端网站线引入 `site/`、GitHub Pages 工作流、发布信息更新脚本与截图脚本；官网将 v0.5.7 标为迭代中，下载仍指向已发布的 v0.5.5。该网站变更尚未部署到 `main`。
- 官网突出书内实际页码：首页标题改为「找到原句，给你书内实际页码」，新增「页码」一节，用《法哲学原理》同一份 PDF 的实测结果对照 PDF 物理页码与书内实际页码（第 69 页 / 序言第 16 页，第 272 页 / 第 201 页），首页演示同时标出两种页码。导入、文献库、检索三张截图按 v0.5.7 在 macOS 上重拍（此前左下角仍为 v0.5.6）；检索截图脚本改为自动选中序言命中并居中高亮。
- Zotero 设置页按确认的原型重排：立即同步移至标题旁，连接与最近同步结果集中在顶部；分类选择与同步设置分栏，窄内容区改为上下排列；一般规则及同步明细按需展开，移除文献的后果常显。关闭同步时禁用分类/频率控件并提示已导入文献保留；未连接时仍可调整同步开关与频率。PDF 解析方式继续共用导入页设置。
- 设置目录采用与原型一致的 Lucide 线性图标，包括译本对齐的语言图标、本地 OCR 的文字扫描、引文格式的引号和书目补全的打开书本；SVG 内联并随包携带 ISC 许可，运行时不增加网络请求。验证范围及浏览器预览限制见 `reports/zotero-settings-ui-2026-09-27.md`。

- 检索、文献库、书目、页码校准、解析服务与导入队列的动态内容改为 DOM 节点构造；来源文本按文本节点显示，检索命中继续使用原有字符区间定位。
- 作品范围、设置中的数据位置/更新/对齐模型、解析统计与备份、知网批量补全拆入独立脚本，继续按编号顺序装配。
- 移除不再使用的 HTML 字符串工厂，更新前端装配与交互守卫。
- 阅读器拆分前新增双窗口装配、公共接口、迟到请求和对齐任务结果的执行型回归测试；阅读器行为未改。
- 阅读器与独立阅读窗口的请求统一经前端请求模块发出；阅读器保留请求注入能力，轮询等需要原始状态码的请求语义不变。
- 译本对齐任务的状态监听独立成前端服务，阅读器与作品页共用同一窗口内的一份轮询；提示归属、结果分类和关闭阅读器后继续监听的行为不变。
- 阅读器单文件拆为 12 个按职责排序的脚本，主窗口和独立窗口仍装配同一份脚本；公共接口、页码与字符区间语义保持不变。四份 macOS/Windows 构建脚本均逐文件检查语法。
- 阅读器打开、关闭和章节跳转改为调用各职责模块的状态重置与失效入口；链接缓存、右栏高亮、引用选区、分页请求和深链定时器均由所属模块写入，新增归属守卫与过期作品请求回归测试。
- 隔离合成 DOCX 的浏览器主窗口已验证搜索结果打开阅读器、三段正文与命中高亮、深链刷新恢复及关闭；隔离开发桌面壳已验证打开阅读器、新窗口与返回主窗口。无出版方页码时如实提示“页码尚未解析”。对照链接/复核完整交互仍待验收。
- Zotero 同步分类初次显示时默认折叠，可逐级展开；在导入页更改 PDF 解析方式后，Zotero 页的方式文案立即更新，无需重启。
- 设置页对齐模型、对齐计算组件、本地 OCR、托管 MinerU 四张组件卡片的轮询与下载/安装/删除操作只采信最后发起的请求；修复迟到的旧轮询把「下载中/安装中」改回「未下载/未安装」并停止刷新（`docs/issues/task-state-request-ordering.md`）。
- 「译本对齐模型」两行改由随包的 Vue 3.5.43 渲染（零构建试点，运行时不联网，阅读器窗口不加载），显示与交互保持不变；修复切换模型被拒时两个选项都显示未选中。主页面体积约增 13%（`docs/issues/vue-pilot-alignment-models.md`）。
- 托管 MinerU 卡片同样改由 Vue 渲染，显示与交互不变；修复不支持 VLM 的电脑上 VLM 一行设为隐藏却仍然显示。新增在 node 中真实渲染 Vue 组件的测试。
- Windows 上每次（重新）对齐不再弹出终端窗口：已安装的独立对齐计算组件是控制台程序，启动时补上隐藏窗口标志；托管 MinerU 硬件检测调用 `nvidia-smi` 同样不再闪窗。本机开发版 `dist/MEFinder` 已按 55f3354 重建替换（构建门禁 2598 项通过）；本节 Windows 验收包已包含此修复。
- Windows 主窗口恢复拖边改变大小：WebView2 盖满无边框窗口后，原生边缘命中测试收不到鼠标，左/右/下边和两个下角既无缩放光标也拉不动。现由页面边缘的透明热区显示缩放光标，按下后交给系统原生缩放（最大化时关闭）。已用真实 pywebview 窗口模拟拖拽实测左边和下边均能缩放。
- 最大化后设置目录不再被截断：大窗口档把目录行距放得过大，1080p 级最大化窗口里「软件更新」等末项掉出视口。行距改为紧凑，只在窗口高度 ≥1100px 时放开；2048×1113 与 1920×1032 视口下 14 项均一屏放下、无滚动条。
- 设置目录与内容区不再常驻灰色滚动条：目录只差十来像素留白时也会出滚动条，现收紧目录上下留白与内容区底部留白，两栏滚动条改为指针停留时才显示（仍可滚动）。已在安装后的 macOS 应用中人工确认。
