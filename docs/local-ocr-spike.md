# 本地 OCR — 质量与运行时验证

**状态：用于校准自动选择，不阻断页图 runner 和结构化接入。**

## 1. 目标

回答三个不能靠源码推导的问题：

1. 哪些探针信号能预测真实 OCR 字符错误率。
2. 双引擎自动选择阈值在未见文献上是否成立。
3. 独立运行时在 Windows 中文路径、取消和长文档条件下是否稳定。

## 2. 语料拆分

真实扫描文献按“文献”为单位拆分，禁止同一本书的页面跨集合：

- 校准集：选择采样策略、指标和阈值。
- 留出集：阈值冻结后只运行一次，用于最终验收。

语料覆盖现代日文横排、现代日文竖排、日文古籍、繁体汉籍、现代繁中和现代简中。文献类型只用于分层报告，**不能作为正负标签**。

每本文献人工标注固定页。统一 CER 规范必须先冻结：Unicode NFC、空白和标点处理、异体字规则、无法辨认字符标记及竖排阅读顺序。

正负标签由实测 CER/可用性定义，例如：

- 可接受：CER 不高于冻结阈值且阅读顺序可用。
- 不可接受：CER 高于阈值或阅读顺序破坏正文。

具体阈值在执行记录中给出理由，不在看数据前写死。

## 3. G1 自动选择质量

两个引擎都只接 MEFinder 渲染的同一批页图。保留：

- 上游原始 JSON。
- 规范化 block 和页文本。
- 检测 confidence（仅作对照）。
- 若 sidecar 能导出，则记录 PARSeq token log-probability、序列均值、低分 token 占比和熵。
- 几何信号：有效行数、墨迹覆盖、竖排行比例、重复行比例。
- 文本信号：词典/语言模型分数；字符集占比不得单独作为质量信号。

在校准集上选择规则并冻结；只在留出集计算误选率、拒绝率、CER 差值和耗时。两个检测器分别是 DEIM 与 RTMDet，其 confidence 不做跨引擎直接比较。

## 4. G2 页图接口与空白页

必须验证：

- runner 命令只含 `--sourceimg`，不含 `--sourcepdf`。
- 现代版不生成 `_text.pdf`。
- 古籍版空白页在调用前由墨迹阈值识别并合成空页，避免 `tatelinecnt/alllinecnt` 除零。
- 非空页 OCR 无结果必须失败，不能冒充空白页。
- 页图、输出和组件路径分别覆盖中文、日文、空格和纯 ASCII。

## 5. G3 数据契约

逐页核对：

- polygon 到 PDF 坐标的缩放。
- 上下左右边界和旋转页。
- `isVertical` 原值与几何推断差异。
- reading order 与人工正文顺序。
- 空白页、插图页和缺页。
- manifest 总页数、分片页范围和最终索引页数一致。

任何缺页、重复页或越界页都是硬失败。

## 6. G4 生命周期

验证两个独立运行时：

- 主进程不 import OCR/onnxruntime 依赖。
- 取消后 5 秒内终止子进程。
- 进程崩溃不产生可 attachment 的半成品。
- 重启复用已验证分片，只重跑缺失分片。
- 两个导入 worker 同时提交时，同一引擎保持单并发。

## 7. G5 分发与合规

在提供一键下载前必须产出：

- 精确组件资产 URL、字节数和 SHA-256。
- 上游 CC BY 4.0 署名、许可证文本和修改说明。
- 第三方依赖 SBOM 与许可证清单。
- Windows/macOS 各自的启动入口和卸载边界。

官方 GUI release ZIP 不能仅凭文件名当作 CLI sidecar；必须实际检查入口并跑通页图命令。

## 8. 产出与放行

产出包括原始结果表、冻结阈值、校准/留出指标、失败样本分类、性能分位数和平台矩阵。

- 留出集达到预定误选率和 CER 目标：启用双引擎质量裁决。
- 未达到：保留首版的保守几何规则，不宣传自动识别准确率。
- 页覆盖、原子 attachment、取消或许可证任一失败：相关功能不得发布。
