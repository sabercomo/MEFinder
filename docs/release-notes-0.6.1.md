# MEFinder 0.6.1（开发中）

## 开发维护

- 修正 SQL 架构检查误报：按文件与完整调用目标排除已核实的搜索服务、解析执行器调用，不再把四个应用服务模块计为数据库查询模块。
- 将 persistence 之外的 SQL 棘轮从文件集合改为逐文件调用数量；已有模块增加 SQL 与新增 SQL 模块均会触发门禁。当前基线为 10 个文件、72 处调用，含解析任务账本的 schema 与事务语句。
- 新增隔离源码树回归测试，覆盖服务与 SQL 混合调用、动态查询、游标、批量执行、未知执行器以及现有模块内增加调用等情况。
- 运行时版本、MCP 契约 release、HTTP 契约快照、Windows 冒烟工作流和相关测试同步到 0.6.1；HTTP 路由与 MCP 工具接口未变。版本展示使前端装配摘要变化，字节数保持不变。

## 范围与限制

本轮只调整开发门禁与版本信息，未迁移业务 SQL 或拆分 PDF 提取模块。静态检查采用已核实目标的精确豁免，不做 Python 类型推断；未知的 `execute*` 调用仍计入棘轮，需审阅后确认归属。

既有 0.6.0 发布说明和安装包保持不变；0.6.1 尚未打包、安装或发布。
