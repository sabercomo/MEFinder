# MEFinder 0.6.3

## 主窗口导航

- MEFinder 名称靠左，右侧按钮可在左侧导航与顶部标签间切换。切换保留当前页面和输入状态，应用记住上次选择。切换动效沿用 Magpie 的实现，遵循系统的减少动态效果设置。
- 展开侧栏时，顶栏显示当前页面名称，设置放在侧栏底部。收起侧栏时，五个导航标签同排显示在圆角分段条内，设置放在右侧。窄窗下导航依次缩为文字和图标，宽度不足 480 px 时使用顶部导航。

## Bug 修复

- MinerU 服务地址支持粘贴官方文档中的完整任务接口 `https://mineru.net/api/v4/extract/task`，连接测试与解析不再重复追加 API 路径。服务根地址、`/api/v4` 和批量上传接口同样支持，自定义代理前缀保留。
- 已有配置在读取时使用规范化地址，无需重新填写，不因读取写回文件；新保存的地址会使用服务根地址。Token 和其他设置保留。
- 沿用 0.6.2 的 SSL 打包修复及连接断开错误提示。核查证据见 [#24 连接报告](../reports/issue-24-connection-validation-2026-11-19.md)。
- 检索界面中的 `$$…$$` 采用独立公式模式，支持 `\tag{1}` 等编号。搜索高亮、上下文和原文复制沿用原始引文定位。

## 兼容性与验证范围

HTTP 路由、MCP 工具、数据库及文献库格式沿用 0.6.2，版本契约快照与前端版本指纹同步为 0.6.3。新增地址回归已在 0.6.2 修复源码中先失败后通过。

## 文字素材库

文字素材库的操作以确认的三级标签样稿为准。上方带校验值的两份早期制品对应此前的 MinerU 修复版。

- 在检索的命中段落中划选原文，选区只给文字着色，旁边显示「复制」和「加标签」。复制保留选中的换行和原文。
- 点击「加标签」后，同一位置可按名称或路径搜索已有标签，点选即收录。也可以输入 `实验/表征/FTIR` 后点「创建并收录」，一次创建缺少的上级并为摘录添加第三级标签。按 Command + 回车（Windows 用 Ctrl + 回车）收录后可继续加下一个标签。点击父标签可汇总下属语料。
- 结构化阅读器也支持收集选区。先前批量收集的完整段落仍可在素材库查看。
- 摘录保存原文和引用位置。重导后凭同一文献中的唯一逐字匹配更新位置。原文无法定位或文献已删除时保留原摘录和出处。
- 支持备注、出处复制和 Markdown 导出。缺少可核定页码时如实提示。数据备份包含素材库快照。索引库升级后，较早版本仅能使用升级前备份的完整数据目录。
