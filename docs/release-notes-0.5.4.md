## 更新内容

### 设置界面（2026-09-13）

- 外观模式卡在 macOS 上整块预览消失已修复：WebKit 里 `<button>` 作 flex 容器时子项不被 stretch，只靠 `aspect-ratio` 取高会塌成 0，`.mode-preview` 补 `width: 100%`（见 `docs/issues/note-macos-mode-preview-collapse.md`）。
- 设置正文铺满内容区，不再是居中窄栏；页面标题放大到 23px 且说明完整换行显示，长说明不再被省略号截断。
- 「独立阅读窗口」「繁简统一检索」等开关行由圆角卡片改为分隔线行；开关轨道统一为 36×22，按下反馈 120ms。
- 「打开 PDF 原文」「段落显示方式」改为下拉行，说明随当前选择切换；「PDF 原文」小节移到「阅读窗口」之前。
- 应用内自绘下拉补齐 `role="option"` 与 `aria-selected`，浮层进入 150ms（减少动态效果时取消）。
- MinerU 账号不再把「从未检测」显示为「可用」：未检测过显示「密钥已保存 · 尚未检测」，本次会话检测结果就地回显，改 Token 或服务地址后旧结论失效。后端补 `last_checked_at` 持久化的待办见 `docs/issues/note-mineru-account-health-honesty.md`。
- 本地 OCR 六态如实呈现：读取失败为「状态未知」（收起全部动作、只留「重新读取」，不按未安装处理），未安装不再摆放看似可用的启用开关，安装失败显示失败阶段与「重试安装」，已安装未启用与已启用分别说明是否参与导入。
- 引文格式与数据备份改为与其余分类一致的行式布局。
- 设计讨论稿（13 个分类的可交互原型）见 `docs/design/settings-prototype.html`。

- 独立阅读窗口开关移至“设置 → PDF 阅读”最上方的“阅读窗口”区域；开关仍默认关闭，开启后下次打开阅读时生效。
- 译本对照重新打开时在跨语言候选中恢复选择，避免中文 PDF 自动对到上次选过的中文 EPUB；不固定优先英文，简繁中文视作同语言，当前阅读中的手动切换保持。

- 检索详情去掉外层圆角卡片与四周留白，宽屏和窄屏均直接铺满内容区；保留正文间距、独立滚动和固定操作栏。

- 设置 → PDF 阅读增加“独立阅读窗口”，默认关闭；开启后结构化阅读和译本对照在原生窗口中打开。
- 每次打开可保留独立的文献、阅读位置和对照状态，主窗口继续搜索。
- 阅读窗口可移动、缩放和关闭；主窗口退出时统一关闭阅读窗口并释放后台。
- 开关从下一次打开阅读时生效，关闭时保留原来的结构化阅读弹层；PDF 原文打开方式保持独立。
- 阅读内容与窗口容器通过小型宿主接口分离，复用原有数据、定位、引文和译本对照逻辑。
- 关闭采用单向窗口状态通知，避免窗口销毁后等待 JS 回执导致进程残留；后台正常收尾，不使用固定延迟销毁或强制退出。

- 新增可重复性能基准：固定合成语料、普通搜索、Markdown/EPUB 导出及真实 MiniLM 对齐期间的搜索；保存 HTTP 失败率、定位一致性、RSS 和后端启动/退出数据，支持同配置前后比较。
