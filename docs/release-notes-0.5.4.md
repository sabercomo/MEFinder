# MEFinder 0.5.4

2026-09-11：macOS arm64 测试包已加入打开已有资料库、阅读及数据位置设置修订，并同步 Windows 迁移缓存修复；全量测试及包校验通过，等待用户安装验收，未正式发布本轮修订。

## 更新内容

- 独立阅读窗口开关移至“设置 → PDF 阅读”最上方的“阅读窗口”区域；开关仍默认关闭，开启后下次打开阅读时生效。
- 译本对照重新打开时在跨语言候选中恢复选择，避免中文 PDF 自动对到上次选过的中文 EPUB；不固定优先英文，简繁中文视作同语言，当前阅读中的手动切换保持。

- 检索详情去掉外层圆角卡片与四周留白，宽屏和窄屏均直接铺满内容区；保留正文间距、独立滚动和固定操作栏。

- 设置 → PDF 阅读增加“独立阅读窗口”，默认关闭；开启后结构化阅读和译本对照在原生窗口中打开。
- 每次打开可保留独立的文献、阅读位置和对照状态，主窗口继续搜索。
- 阅读窗口可移动、缩放和关闭；主窗口退出时统一关闭阅读窗口并释放后台。
- 开关从下一次打开阅读时生效，关闭时保留原来的结构化阅读弹层；PDF 原文打开方式保持独立。
- 阅读内容与窗口容器通过小型宿主接口分离，复用原有数据、定位、引文和译本对照逻辑。
- 关闭采用单向窗口状态通知，避免窗口销毁后等待 JS 回执导致进程残留；后台正常收尾，不使用固定延迟销毁或强制退出。

- 新增可重复性能基准：固定合成语料、普通搜索、Markdown/EPUB 导出及真实 MiniLM 对齐期间的搜索；保存 HTTP 失败率、定位一致性、RSS 和后端启动/退出数据，支持同配置前后比较。

## 2026-09-11 — 已有资料库与设置修订

- 设置 → 数据位置新增「打开已有资料库」，只读验证已有索引，保存下次启动的读取位置，不复制或覆盖原库；原来的搬迁操作独立保留为「迁移当前资料库」。

- 新增真实书库快照基准驱动：65 本真实文献的隔离快照、固定八条查询、真实 Markdown/EPUB 导出及 MiniLM 对齐；计时结果只保留摘要，不提交私人书库及原句。首轮三轮基线见 [真实库基线报告](../reports/performance-real-v0.5.4-2026-09-11.md)。
