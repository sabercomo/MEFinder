# MEFinder v0.5.4 发布说明

**2026-09-10: 修复版本，解决数据迁移功能 bug，可正常使用。**

---

## 修复内容

### 数据迁移功能修复
- **修复**：数据迁移时目标目录检查逻辑错误，导致迁移无法正常启动
- **影响**：v0.5.3 用户尝试迁移数据位置时会遇到"目标目录必须为空"的误报
- **根因**：`exists_and_not_empty()` 辅助函数判断逻辑反向，将"不存在或为空"误判为"存在且非空"
- **解决**：修正判断逻辑，现在正确识别空目录或不存在的目录为合法迁移目标
