# MEFinder 0.5.4

2026-09-10：独立阅读窗口的关闭回执死锁已修复，macOS 隐藏原生窗口及自然退出回归通过；可继续开发验证，尚未构建或发布安装包。

## 更新内容

- 设置 → PDF 阅读增加“独立阅读窗口”，默认关闭；开启后结构化阅读和译本对照在原生窗口中打开。
- 每次打开可保留独立的文献、阅读位置和对照状态，主窗口继续搜索。
- 阅读窗口可移动、缩放和关闭；主窗口退出时统一关闭阅读窗口并释放后台。
- 开关从下一次打开阅读时生效，关闭时保留原来的结构化阅读弹层；PDF 原文打开方式保持独立。
- 阅读内容与窗口容器通过小型宿主接口分离，复用原有数据、定位、引文和译本对照逻辑。
- 关闭采用单向窗口状态通知，避免窗口销毁后等待 JS 回执导致进程残留；后台正常收尾，不使用固定延迟销毁或强制退出。

## 验证与边界

全量 unittest 2094 项通过（22 项条件跳过，含需显式启用的原生测试），Ruff F、Node 语法及前端守卫通过。
macOS 原生测试单独启用通过：默认弹层、独立锚点与对照状态、移动缩放、正文填满窗口、关闭后重开及整个进程自然退出。
修复场景连续 3 次自然退出；旧关闭 API 在隔离对照实验中仍复现回执线程卡死。
此前另一例无栈转圈的原因尚不能确认相同；可见交互最终验收、Windows 原生 GUI 与两平台成品构建仍属后续发布门禁。
