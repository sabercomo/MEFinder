**事实**：[时序复现、源码侧测量与 Windows 复测方法](../../reports/windows-startup-0.6.6-2026-11-23.md)记录了一处加载页漏跳转和一处 PDF 渲染库提前导入。测试不含 Windows 打包启动时间。
