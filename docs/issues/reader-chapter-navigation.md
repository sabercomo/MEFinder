# 阅读器章节目录与双语跳转

2026-09-18：章节目录已实现于源码，未重建安装包。复用数据库中的一、二级标题；不重新解析源文件。

## 数据与接口（事实）

- 新增 `GET /api/document/outline?source_id=…`。仅允许一次 `source_id`；返回 `source_file_id`、`offset_unit=unicode_codepoint`、`entries`。
- 每个条目包含 `title`、`level`（1 或 2）、`item_index`（PDF 物理页索引或文本段落索引）、`anchor_id`（旧 PDF 可为空）、`char_start`、`char_end`（原始正文的 Unicode 码点区间）。不返回推算页码。
- PDF 通过 `markdown_export_normalize.reader_heading_spans` 复用 `trusted_heading`、重复页眉页脚识别和正文块校验。没有准确文本区间的标题不输出；旧块缺偏移时，仅在块文本与原页吻合后按阅读顺序查找其精确原文位置。
- EPUB 的 h1/h2 与 Word 的 Heading 1/2、标题 1/2 取自入库 `style_name`。不按文字长短、加粗或章节词汇猜标题。
- 全书目录按需读取；PDF 两次流式扫描（页眉统计、标题提取），前端只缓存当前文献的目录，切换文献即失效。
- 无标题返回空数组；参数错误 400、文献不存在 404、索引重建 503、存储失败 500。无 schema 或模型依赖变更。

## 交互（事实）

- 工具栏「目录」默认收起；下拉显示原始层级、标题换行、二级缩进，支持上下键、Home/End、Enter/空格与 Escape，收起后焦点回到入口。
- 点击章节按标题锚点和字符区间定位左栏，再经对齐接口定位右栏，不按两本书的章节序号强配。
- 目录点击同步一次，独立于滚动跟随开关；跳转期间抑制滚动跟随，避免页面中心定位覆盖章节定位。
- 没有对应、无可读对齐或请求失败，左栏仍可导航；右栏不假跳转、不保留误导的旧高亮。网络/定位错误保留具体说明。
- 快速连续点章节、关闭阅读器或切换文献时，旧请求不会覆盖新导航；旧书目录响应也不会覆盖新书。

## 验收证据（事实）

- `tests/test_document_outline.py`：PDF 一二级筛选、重复页眉排除、已验证书签例外、错位块排除、旧块重复标题顺序定位、Unicode 码点、EPUB/Word 样式与不虚构页码、空目录与非法文献。
- `tests/test_reader_outline_frontend.py` 执行实际 JS：暂停跟随仍同步一次、连续点击与关闭淘汰旧结果、无对应保持右栏滚动位置并清除旧高亮、旧书目录响应淘汰。
- `tests/test_structured_reader_web.py` 通过真实 HTTP 验证端点挂载、空结果及 400/404；HTTP 路由契约与前端装配指纹同步。
- 实际书库快照副本：法哲学原理 EPUB 返回 20 条目录。点击 Morality，左栏高亮第 989 段标题，右栏高亮德文 PDF 索引 124 的 `zweiter teil / DIE MORALITÄT`；方向键与 Escape 正常。720px 宽窗口目录右边界 474px，文档 scrollWidth=720，无横向溢出。
- 同作品的旧 PDF 快照没有保存可用标题层级，目录为空，未重新解析这些 PDF。这不是根据现有原文件推断其有无目录。

## 限制与后续

- 本轮不补旧书缺失的结构数据，不改对齐算法、默认 batch64 或正式书库。
- 单向滚动跟随规则不变；目录是一次明确的双栏定位动作。
- 桌面包新窗口往返与跨平台冻结发布验收仍保留原待办。
