# PDF 截图预览占用搜索锁

2026-11-23：已在工作区修复，未提交或发布。
2026-11-24：已随 0.6.6 提交，尚未发布。

**事实。** 旧实现把 PDF 渲染、编码放在搜索共用的状态锁内。固定事件顺序后，搜索无法在人工暂停的渲染继续前完成；旧预览凭据也未绑定来源或物理页。[报告](../../reports/materials-pdf-preview-2026-11-23.md)记录了改前复现和改后回归。

**边界。** 渲染移出状态锁，保留阻止索引发布和素材写入与预览交叉的变更锁，以及数据目录迁移门禁。只解决这类锁等待，未测大型 PDF 的 CPU 开销或 Windows 实机延迟。
