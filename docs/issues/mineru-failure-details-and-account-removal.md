# MinerU 失败原因被汇总层覆盖与失效账号无法删除

## 2026-11-06 — 已复现并实施修复

**事实**：`me2-38.pdf` 的分片账本保存了 HTTP 401 / A0211 与 Token 失效的具体中文提示，整书引擎却固定写入英文通用错误；云端桥接层又把永久失败一律标成可中断恢复。另一条账号删除查询仅看分片状态，没有检查整书是否已经终止，导致当前占用为 0 的失效账号也无法删除。运行证据、用户授权的本机删除操作与回归测试见[核验报告](../../reports/mineru-error-diagnostics-2026-11-06.md)。

**修复**：整书提示保留失败页段和原始原因；永久失败不再承诺复用断点；账号删除查询与在途计数采用相同的整书终态范围。真实活跃任务仍保留删除保护，历史解析结果不删除。

**推断**：这两处状态判定不一致，使用户把鉴权失败误认为服务暂时中断，又无法移除失效账号；本轮回归验证针对这条具体故障路径，不对 MinerU 云端总体稳定性作结论。
