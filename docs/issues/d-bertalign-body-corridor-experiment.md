# D：Bertalign 两步法实验

状态：2026-09-06 已完成初始真机实验及四条原书抽查；不进入 0.5.2 正式 DP。结果见 `reports/d-bertalign-experiment-2026-09-06.md`。

方法依据：[Bertalign 原作者仓库](https://github.com/bfsujason/bertalign) 与 [Liu & Zhu 论文](https://doi.org/10.1093/llc/fqac089)。先用 1:1 对齐建立近似锚点，再沿受约束路径做多对多恢复；不能把简单放宽当前 DP 的最大块长称作复现 Bertalign。

实验约束：

1. 输入为固定分段集、固定模型缓存及已复核正文区域；数据库只读，结果单独输出。
2. 恢复范围取相邻可靠锚点间的双侧正文开区间，不含锚点本身；无双侧边界的首尾区域不恢复，不跨区域或跨锚点。
3. 副文本与集中尾注禁止进入候选；不能仅以“当前没有 accepted 链接”判断可恢复。
4. 同一缓存分别评估当前 DP、两阶段恢复；记录完整成员集合与分数、耗时、峰值内存、覆盖冲突及人工/AI 原书判定来源。
5. 正确与部分对应分开计分，不能用 unmatched 降幅代替准确率。37 条现有复核只作定向回归集，另抽正文新增恢复候选核对原书。

已完成：20 个固定分段集正文边界复核；缓存求和原型对照；固定上游 corelib 两阶段 DP + 真实拼接文本 E5 嵌入；一个结构走廊 226 条链接，唯一覆盖旧 unmatched 的候选核对为正文正确。

后续门禁：扩展跨书正文走廊样本，评估覆盖冲突、准确率与耗时后再决定是否接入正式 DP。未编号标题及重复 Notes 的新书自动识别仍有局限，不得把本批复核边界当通用规则。脚注/尾注覆盖冲突另见 `note-layout-alignment-conflicts.md`。

新增阻断证据：全库复核发现 FR→ZH 的 `term:l-age-d-or` 同词异义锚点，以及 JA→ZH 的跨章 `number:18` 锚点。旧 MiniLM 和新 E5 均存在，不能把“当前已有锚点”视为“可靠锚点”。扩大 D 前须在实验路径验证锚点筛选；本轮未擅改正式锚点算法。详见 `reports/e5-full-rerun-2026-09-06.md`。
